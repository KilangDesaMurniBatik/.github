# Kilang Desa Murni Batik

**Platform e-dagang lengkap untuk batik Malaysia** | Full-stack e-commerce platform for Malaysian batik

---

### Apa Yang Kami Bina

Kilang Desa Murni Batik ialah platform digital yang menghubungkan kilang batik tradisional dengan pembeli moden. Sistem kami merangkumi keseluruhan proses operasi - dari pengurusan katalog produk hingga pemenuhan pesanan.

### Keupayaan Platform

- **Kedai Online** - Laman web e-dagang untuk pelanggan membeli batik secara terus
- **Panel Admin** - Dashboard pengurusan pesanan, inventori, pelanggan dan pelaporan
- **Integrasi Marketplace** - Penyegerakan automatik dengan Shopee dan TikTok Shop
- **Sistem Ejen** - Pengurusan rangkaian ejen jualan dan komisyen
- **Pengurusan Inventori** - Penjejakan stok masa nyata merentasi semua saluran jualan
- **Pemprosesan Pesanan** - Aliran kerja pesanan dari pembelian hingga penghantaran

### Teknologi

Dibina menggunakan seni bina perkhidmatan mikro (microservices):

| Lapisan | Teknologi |
|---------|-----------|
| Backend | Go, Gin, GORM, PostgreSQL |
| Frontend | Next.js, TypeScript, Tailwind CSS |
| Infrastruktur | Docker, NATS, Redis, MinIO |
| Marketplace | Shopee Open Platform API, TikTok Shop API |
